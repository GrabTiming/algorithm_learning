# 算法练习仓库

本仓库用于记录和练习算法题（主要为 C++ 实现）。结构清晰、按平台分类，适合刷题记录与复盘。

目录结构（简要说明）：

- `template.cpp` — 通用 C++ 模板
- `Atcoder/` — Atcoder 练习题代码（按赛题目录存放）
- `luogu/` — Luogu 练习题代码
- `nowcoder/` — 牛客网/练习题代码
- `output/` — （本地测试输出目录）

如何编译运行单个题目（示例）：

```bash
# 编译（C++17）
 g++ -std=c++17 -O2 -pipe -o solution path/to/file.cpp
# 运行
 ./solution < input.txt > output.txt
```
